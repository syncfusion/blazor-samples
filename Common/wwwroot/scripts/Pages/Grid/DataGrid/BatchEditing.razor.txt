<ActionDescription>
<p>This sample demonstrates how to use batch editing mode in the DataGrid to perform CRUD operations efficiently.</p>
  
  <p>The Blazor DataGrid batch editing feature enables you to start editing by double-clicking a cell and modifying its value. You can perform CRUD operations as follows:</p>
  <ul>
    <li><strong>Add</strong> - Click the Add toolbar button to create a new record.</li>
    <li><strong>Edit</strong> - Double-click a row or click the Edit toolbar button after selecting a row to modify data.</li>
    <li><strong>Delete</strong> - Click the Delete toolbar button after selecting a row to remove a record.</li>
    <li><strong>Update</strong> - Click the Update toolbar button to save all edited changes.</li>
    <li><strong>Cancel</strong> - Click the Cancel toolbar button to discard all edited changes.</li>
    <li><strong>Undo</strong> - Click the Undo toolbar button or press <strong>Ctrl+Z</strong> to reverse the most recent batch editing action.</li>
    <li><strong>Redo</strong> - Click the Redo toolbar button or press <strong>Ctrl+Y</strong> to reapply the most recently undone action.</li>
  </ul>
  
    <p>CRUD operations are configured in the DataGrid using the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Grids.GridEditSettings.html' aria-label="Navigate to the class reference for GridEditSettings">GridEditSettings</a> component. You must define at least one column as a primary key using the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Grids.GridColumn.html#Syncfusion_Blazor_Grids_GridColumn_IsPrimaryKey' aria-label="Navigate to the IsPrimaryKey property reference for Grid column">IsPrimaryKey</a> property in the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Grids.GridColumn.html' aria-label="Navigate to the class reference for GridColumn">GridColumn</a> component.</p>
  
  <p>The available edit modes are:</p>
  <ul>
    <li><strong>Inline</strong> - Edit records directly within the grid rows</li>
    <li><strong>Dialog</strong> - Edit records in a modal dialog</li>
  </ul>
  
  <p>By default, new rows are added at the top of the DataGrid. You can change this behavior by setting the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Grids.GridEditSettings.html#Syncfusion_Blazor_Grids_GridEditSettings_NewRowPosition' aria-label="Navigate to the NewRowPosition property reference for Grid edit settings">NewRowPosition</a> property to <strong>Batch</strong> in <code>GridEditSettings</code>.</p>
   
  <p>Undo and redo support is enabled by setting the <code>EnableUndoRedo</code>property to <strong>true</strong> in <code>GridEditSettings</code>. It is supported only in batch edit mode and maintains a history of cell edits, row additions, row deletions, paste operations, and autofill operations. In this sample, use the checkbox to dynamically enable or disable the feature.</p>

  <p>In this demo, batch mode is enabled by setting the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Grids.GridEditSettings.html#Syncfusion_Blazor_Grids_GridEditSettings_Mode' aria-label="Navigate to the Mode property reference for Grid edit settings">Mode</a> property to <strong>Batch</strong> in the <code>GridEditSettings</code> component. Begin editing by double-clicking a cell and changing its value. When navigating to a new cell, the edited cell is highlighted to indicate which cells have been modified. Bulk save all edited data to the datasource by clicking the <strong>Update</strong> button on the toolbar.</p>
  
  <p>For more detailed information about batch editing, refer to the <a rel="noopener" target='_blank' href='https://help.syncfusion.com/grid-sdk/blazor/data-grid/batch-editing' aria-label="Navigate to the documentation for Batch editing in DataGrid component">batch editing documentation</a>.</p>

  <p>Looking for the full Blazor DataGrid component overview, features, pricing, and documentation? Visit our <a rel="noopener" target='_blank' href='https://www.syncfusion.com/blazor-components/blazor-datagrid' aria-label="Navigate to the Blazor DataGrid FT page">Blazor DataGrid component</a> page.</p>

@code {

    public List<InventoryStoreRecord>? GridData { get; set; }
    private bool enableUndoRedo;
    private bool isUndoRedoEnabled;
    private List<string> ToolbarItems => enableUndoRedo
        ? new List<string> { "Add", "Delete", "Update", "Cancel", "Undo", "Redo" }
        : new List<string> { "Add", "Delete", "Update", "Cancel" };

	private async Task OnEnableUndoRedoChange(Microsoft.AspNetCore.Components.ChangeEventArgs args)
    {
        if (args.Value is bool checkedValue)
        {
            enableUndoRedo = checkedValue;
        }
    }

	private static string CategoryBadgeClass(string category)
    {
        return category switch
        {
            "IT Asset" => "e-cat-it-asset",
            "IT Infrastructure" => "e-cat-it-infrastructure",
            "Admin" => "e-cat-admin",
            "Security" => "e-cat-security",
            "Facilities" => "e-cat-facilities",
            "Finance" => "e-cat-finance",
            "Sales" => "e-cat-sales",
            "Marketing" => "e-cat-marketing",
            "Training" => "e-cat-training",
            _ => "e-cat-default"
        };
    }

    protected override void OnInitialized()
    {
        GridData = InventoryStoreData.GetAllRecords().ToList();
    }

}
