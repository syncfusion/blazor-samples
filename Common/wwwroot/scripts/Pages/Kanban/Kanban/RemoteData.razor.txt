<ActionDescription>
<p>
    This sample demonstrates binding remote data to the <a class="e-kanban-remotedata-reference-link" aria-label="Navigate to the explore Syncfusion Blazor Kanban component"
                                                                                                              href="https://www.syncfusion.com/gantt-sdk/blazor-kanban-board"
                                                                                                              target="_blank" rel="noopener">Blazor Kanban</a> component using the DataManager by visualizing a software development task tracker. The board fetches bug reports and feature requests from a remote endpoint and groups them by workflow status.
</p>
<p>
    Assign an instance of <code>DataManager</code> to the Kanban <code>DataSource</code> to enable remote data binding. The <a class="e-kanban-remotedata-reference-link" aria-label="Navigate to the Blazor DataManager Getting Started documentation"
                                                                                                              href="https://blazor.syncfusion.com/documentation/data/getting-started"
                                                                                                              target="_blank" rel="noopener">DataManager</a> acts as an interface between the service endpoint and the Kanban component and requires the following minimal configuration:
</p>
<ul>
    <li><a class="e-kanban-remotedata-reference-link" aria-label="Navigate to the API reference of Url property in DataManager"
           href="https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.DataManager.html#Syncfusion_Blazor_DataManager_Url"
           target="_blank" rel="noopener">DataManager.Url</a> – Defines the endpoint to fetch data.</li>
    <li>
        <a class="e-kanban-remotedata-reference-link" aria-label="Navigate to the API reference of Adaptor property in DataManager"
           href="https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.DataManager.html#Syncfusion_Blazor_DataManager_Adaptor"
           target="_blank" rel="noopener">DataManager.Adaptor</a> – Specifies the adaptor. By default, <code>ODataAdaptor</code> is used. The adaptor processes requests/responses. The <a class="e-kanban-remotedata-reference-link" aria-label="Reference of Blazor Data NuGet Package"
                                                                                                              href="https://www.nuget.org/packages/Syncfusion.Blazor.Data/"
                                                                                                              target="_blank" rel="noopener">Syncfusion.Blazor.Data</a> package includes adaptors like:
        <ul>
            <li><code>UrlAdaptor</code> – Interact with generic remote services.</li>
            <li><code>ODataAdaptor</code> – For OData endpoints.</li>
            <li><code>ODataV4Adaptor</code> – For OData V4 endpoints.</li>
            <li><code>WebApiAdaptor</code> – For Web API endpoints under OData standards.</li>
            <li><code>WebMethodAdaptor</code> – For web methods.</li>
        </ul>
    </li>
</ul>
<p>
    Additional essential interactions that enhance analysis and control are also featured:
</p>
<ul>
    <li>
        <a aria-label="Navigate to the documentation for the columns in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/columns"
           target="_blank" rel="noopener">Columns</a>: Group cards by workflow stage such as To Do, In Progress, Testing, and Done.
    </li>
    <li>
        <a aria-label="Navigate to the documentation for the data binding in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/data-binding"
           target="_blank" rel="noopener">Data Binding</a>: Fetch cards on demand from a remote endpoint using a configured <code>SfDataManager</code>.
    </li>
    <li>
        <a aria-label="Navigate to the documentation for the dialog events in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/events"
           target="_blank" rel="noopener">Dialog Cancel</a>: The default card dialog is suppressed so the board behaves as a read-only tracker.
    </li>
</ul>
<p>
    Key interactive features demonstrated in this sample include:
</p>
<ul>
    <li><b>Remote Data Binding</b>: Cards are fetched from a remote service through <code>SfDataManager</code> using the <code>WebApiAdaptor</code>.</li>
    <li><b>Cross Domain Support</b>: The <code>CrossDomain</code> flag on <code>SfDataManager</code> enables requests to the hosted demo endpoint.</li>
    <li><b>Disabled Drag and Drop</b>: Drag and drop is disabled in this demo so the remote state is not mutated from the client.</li>
    <li><b>Read-only Board</b>: The default edit dialog is cancelled via the <code>DialogOpen</code> event to keep the board display-only.</li>
</ul>
<p>
    The <b>Data Binding</b> panel highlights the supported ways to populate the board from a remote source:
</p>
<ul>
    <li><b>SfDataManager</b>: A <code>SfDataManager</code> is assigned directly to the Kanban <code>DataSource</code> property to wire up remote data.</li>
    <li><b>Adaptor Selection</b>: The <code>WebApiAdaptor</code> is used to communicate with the Web API endpoint exposed by Syncfusion.</li>
    <li><b>Column Mapping</b>: The <code>KeyField</code> on each column maps to the <code>Status</code> field returned by the remote service.</li>
</ul>

@code{
    
    private List<ColumnModel> ColumnData = new List<ColumnModel>() 
    {
        new ColumnModel(){ HeaderText= "To Do", KeyField= new List<string>() { "Open" } },
        new ColumnModel(){ HeaderText= "In Progress", KeyField= new List<string>() { "InProgress" } },
        new ColumnModel(){ HeaderText= "Testing", KeyField= new List<string>() { "Testing" } },
        new ColumnModel(){ HeaderText= "Done", KeyField=new List<string>() { "Close" } }
    };

    public class KanbanDataModel
    {
        public int Id { get; set; }
        public string? Status { get; set; }
        public string? Summary { get; set; }
        public string? Type { get; set; }
        public string? Priority { get; set; }
        public string? Tags { get; set; }
        public double Estimate { get; set; }
        public string? Assignee { get; set; }
        public string? ImgUrl { get; set; }
        public int RankId { get; set; }
    }
        private string GetInitials(string? name)
    {
        if (string.IsNullOrEmpty(name)) return "?";
        var parts = name.Split(' ');
        return parts.Length > 1 ? $"{parts[0][0]}{parts[1][0]}".ToUpper() 
                                 : name[0].ToString().ToUpper();
    }

    private string GetColorByPriority(string? priority)
    {
        return priority switch
        {
            "Critical" => "#b71c1c",
            "High" => "#d32f2f",
            "Normal" => "#1976d2",
            "Low" => "#388e3c",
            _ => "#666"
        };
    }
}
