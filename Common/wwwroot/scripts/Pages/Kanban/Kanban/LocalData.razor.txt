<ActionDescription>
<p>
    This sample demonstrates binding an array of objects (local data source) to the <a class="e-kanban-localdata-reference-link" aria-label="Navigate to the explore Syncfusion Blazor Kanban component"
                                                                                                            href="https://www.syncfusion.com/gantt-sdk/blazor-kanban-board"
                                                                                                            target="_blank" rel="noopener">Blazor Kanban</a> component by visualizing a Local Renovation Tasks. The board renders a predefined list of bug reports and feature requests grouped by workflow status.
</p>
<p>
    Bind data to the board using the <a class="e-kanban-localdata-reference-link" aria-label="Navigate to the API reference of DataSource property in Kanban"
                                                                                                            href="https://help.syncfusion.com/cr/blazor/Syncfusion.Blazor.Kanban.SfKanban-1.html#Syncfusion_Blazor_Kanban_SfKanban_1_DataSource"
                                                                                                            target="_blank" rel="noopener">DataSource</a> property, which accepts an array of objects or a <code>DataManager</code> instance. In this demo, an array of objects is assigned to render columns and cards.
</p>
<p>
    Additional essential interactions that enhance analysis and control are also featured:
</p>
<ul>
    <li>
        <a aria-label="Navigate to the documentation for the columns in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/columns"
           target="_blank" rel="noopener">Columns</a>: Group cards by workflow stage such as To Do, In Progress, Testing, and Done.
    </li>
    <li>
        <a aria-label="Navigate to the documentation for the card settings in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/cards"
           target="_blank" rel="noopener">Card Settings</a>: Map the title and summary fields to display rich card content sourced from local data.
    </li>
    <li>
        <a aria-label="Navigate to the documentation for the drag and drop in the kanban component"
           href="https://blazor.syncfusion.com/documentation/kanban/drag-and-drop"
           target="_blank" rel="noopener">Drag and Drop</a>: Move cards between columns to update their workflow status with a single action.
    </li>
</ul>
<p>
    Key interactive features demonstrated in this sample include:
</p>
<ul>
    <li><b>Local Data Binding</b>: An in-memory array of task objects is supplied to the <code>DataSource</code> property, eliminating the need for a remote endpoint.</li>
    <li><b>Column Mapping</b>: The <code>KeyField</code> on each column maps to the <code>Status</code> field of the data to position cards correctly.</li>
    <li><b>Card Display</b>: Each card shows the task ID and summary text, which is rendered from the bound local data.</li>
    <li><b>Auto Layout</b>: Columns are automatically sized to fit the available board width without any manual configuration.</li>
</ul>
<p>
    The <b>Data Source</b> panel highlights the supported ways to populate the board:
</p>
<ul>
    <li><b>Array of Objects</b>: A simple, strongly typed <code>KanbanDataModel</code> list is used as the data source in this demo.</li>
    <li><b>KeyField Mapping</b>: The <code>KeyField</code> property of the Kanban and each column maps the data field that drives column placement.</li>
</ul>
