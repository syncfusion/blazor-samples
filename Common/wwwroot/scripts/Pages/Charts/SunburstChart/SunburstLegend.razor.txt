<ActionDescription>
<p>This Blazor Sunburst Chart example visualizes <b>Global Workforce and Talent Distribution (in Thousands of Employees)</b> across international delivery hubs (USA, India, Germany, and UK) grouped by organizational department and specialized job roles.</p>

<p>In this example, you can see how to render and configure a sunburst chart with an interactive legend and asymmetric, multi-depth branch structures resembling a sun flare. Key features demonstrated here include:</p>
<ul>
    <li><code>SunburstLegendSettings</code> with <code>Visible</code> set to <code>true</code> and <code>Position</code> set to <code>Top</code> for a clear regional legend</li>
    <li><code>ToggleVisibility</code> set to <code>true</code> allowing interactive hiding and showing of regional branches</li>
    <li>Asymmetric depth across branches (some branches reach 4 levels deep while others stay at 2 or 3 levels) creating a distinct sunburst flare silhouette</li>
    <li><code>SunburstDataLabelSettings</code> with <code>LabelRotationMode</code> set to <code>Angle</code> and <code>LabelOverflowMode</code> set to <code>Trim</code> for readable curved labels</li>
    <li><code>SunburstTooltipSettings</code> with <code>EnableHighlight</code> providing clean hovered segment context</li>
    <li>A custom <code>Palette</code> aligned to the active theme to color regional sectors consistently</li>
</ul>

<p><code>Tooltip</code> is enabled in this example. To see tooltip details, hover over or tap on a segment. Click a legend item to toggle its visibility.</p>

<p>More information about the sunburst chart legend can be found in this <a target='_blank' href='https://blazor.syncfusion.com/documentation/sunburst-chart/legend' aria-label="Navigate to the documentation for sunburst chart legend" rel='noopener'>documentation section</a>.</p>
</ActionDescription>

<div class="control-section" align='center'>
    <SfSunburstChart TItem="NodeDetails"
                     DataSource="@data"
                     Palette="@Palette"
                     IdMemberPath="@nameof(NodeDetails.Id)"
                     ParentIdMemberPath="@nameof(NodeDetails.ParentId)"
                     LabelMemberPath="@nameof(NodeDetails.Name)"
                     ValueMemberPath="@nameof(NodeDetails.Value)"
                     InnerRadius="0.2"
                     Radius="@Radius"
                     StartAngle="0"
                     EndAngle="360"
                     Title="Global Workforce Distribution"
                     Subtitle="Source: Statista Global Workforce Report, 2025"
                     ID="employeesCountChart"
                     Theme="@Theme"
                     Width="@Width"
                     Height="@Height"
                     EnableAnimation="true"
                     AnimationType="SunburstAnimationType.Rotation">
        <SunburstTitleSettings FontWeight="600" Size="16px" />
        <SunburstSubtitleSettings FontWeight="400" Size="12px" />

        <SunburstLegendSettings Visible="true"
                                Position="SunburstLegendPosition.Top"
                                ToggleVisibility="true">
            <SunburstLegendTextStyle FontWeight="400" />
        </SunburstLegendSettings>

        <SunburstDataLabelSettings Visible="true"
                                   RotationMode="SunburstLabelRotationMode.Angle">
            <SunburstDataLabelTextStyle FontWeight="500" />
        </SunburstDataLabelSettings>

        <SunburstTooltipSettings Enable="true"
                                 EnableHighlight="true"
                                 HeaderText="Workforce Distribution"
                                 Format="${point.label} : ${point.value}" />
    </SfSunburstChart>
</div>

    }
