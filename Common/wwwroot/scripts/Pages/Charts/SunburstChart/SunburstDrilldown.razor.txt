<ActionDescription>
<p>This Blazor Sunburst Chart example visualizes <b>Book Sales and Publications Volume (in Thousands of Units)</b> across major reading categories, age demographics, genres, and specific book editions.</p>

<p>In this example, you can see how to render and configure a sunburst chart with drill-down functionality and asymmetric hierarchical depths creating a dynamic sun flare shape. Key features demonstrated here include:</p>
<ul>
    <li><code>SunburstDrillSettings</code> with <code>Enable</code> set to <code>true</code> enabling click-to-expand drill navigation</li>
    <li><code>ShowBreadcrumbs</code> set to <code>true</code> rendering an interactive breadcrumb trail at the top of the chart to navigate back to parent levels</li>
    <li>Uneven hierarchical branches (ranging from 2 levels for Magazines up to 4 levels for Children's and Fiction) mimicking natural hierarchical variations</li>
    <li><code>SunburstLegendSettings</code> positioned at the <code>Right</code> with toggle capabilities</li>
    <li><code>LabelRotationMode</code> set to <code>Angle</code> so radial text remains readable as you drill down and back up</li>
    <li><code>EnableAnimation</code> with <code>AnimationType</code> set to <code>Rotation</code> for animated transitions between hierarchical depths</li>
    <li>A custom <code>Palette</code> aligned to the active theme to color primary book categories consistently</li>
</ul>

<p><code>Tooltip</code> is enabled in this example. To see tooltip details, hover over or tap on a segment. Click any slice to drill into its sub-tree, and click the breadcrumbs to drill back up.</p>

<p>More information about the sunburst chart drill-down can be found in this <a target='_blank' href='https://blazor.syncfusion.com/documentation/sunburst-chart/drill-down' aria-label="Navigate to the documentation for sunburst chart drill-down" rel='noopener'>documentation section</a>.</p>
</ActionDescription>

<div class="control-section" align='center'>
    <SfSunburstChart TItem="NodeDetails"
                     DataSource="@data"
                     Palette="@Palette"
                     IdMemberPath="@nameof(NodeDetails.Id)"
                     ParentIdMemberPath="@nameof(NodeDetails.ParentId)"
                     LabelMemberPath="@nameof(NodeDetails.Name)"
                     ValueMemberPath="@nameof(NodeDetails.Value)"
                     InnerRadius="0.15"
                     Radius="@Radius"
                     Title="Book Sales & Publications Volume"
                     Subtitle="Source: Publishers Weekly & BookScan Report, 2024"
                     ID="businessOpsChart"
                     Theme="@Theme"
                     Width="@Width"
                     EnableAnimation="true"
                     AnimationType="SunburstAnimationType.Rotation"
                     Height="@Height">
        <SunburstTitleSettings FontWeight="600" Size="16px" />
        <SunburstSubtitleSettings FontWeight="400" Size="12px" />

        <SunburstLegendSettings Visible="true"
                                Position="@LegendPosition"
                                ToggleVisibility="true">
            <SunburstLegendTextStyle FontWeight="400" />
        </SunburstLegendSettings>

        <SunburstDataLabelSettings Visible="true"
                                   RotationMode="SunburstLabelRotationMode.Angle">
            <SunburstDataLabelTextStyle FontWeight="500" />
        </SunburstDataLabelSettings>

        <SunburstTooltipSettings Enable="true"
                                 EnableHighlight="true"
                                 HeaderText="Book Publications"
                                 Format="${point.label} : ${point.value}" />

        <SunburstDrillSettings Enable="true" ShowBreadcrumbs="true" />
    </SfSunburstChart>
</div>

    public string FontFamily { get; set; } = "Roboto";
    public SunburstLegendPosition LegendPosition { get; set; } = SunburstLegendPosition.Right;

    private string[] Palette = Array.Empty<string>();

    protected override void OnInitialized()
    {
        Theme = ThemeHelper.GetCurrentTheme(NavigationManager.Uri);
        FontFamily = ThemeHelper.GetFontFamily(NavigationManager.Uri);
        Palette = SunburstThemeColors.GetDrilldownPalette(Theme);

        @*Hidden:Lines*@
        if (SampleService != null && SampleService.IsDevice)
        {
            Width = "100%";
            Height = "360px";
            Radius = 0.85;
            LegendPosition = SunburstLegendPosition.Bottom;
        }
        @*End:Hidden*@
    }
